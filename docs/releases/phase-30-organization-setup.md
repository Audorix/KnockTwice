# Phase 30 - Guided organization setup

Organization owners and administrators now see a setup checklist on the organization profile. It
links to the existing logo editor, first-workspace controls, and member/invitation management where
the inviter chooses each teammate's role. Steps reflect the organization's current logo, workspace,
members, and pending invitations. Members do not see the checklist; owners and administrators can
hide it for the current page visit.
